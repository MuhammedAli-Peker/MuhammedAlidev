# Python Learning Journey

A collection of Python mini-projects built while learning the language from the ground up — starting with fundamentals (data types, conditionals, loops, functions) and progressing toward object-oriented programming.

The focus of this repository is **understanding over speed**: each project is built by first reasoning through the algorithm, then implementing it, with an emphasis on writing clean, readable code rather than rushing to finish.

## Structure

Each project lives in its own folder (or file) and includes its own `README.md` with project-specific details, usage instructions, and notes.

```
python-learning-journey/
├── inventory_tracker/       # Lost item / inventory tracking CLI app
├── address_book/            # Simple address book (in progress)
└── ...                      # More projects added as they're completed
```

## Concepts Practiced

- Working with lists of dictionaries (multi-attribute data structures)
- Index-based access and reference/alias semantics
- Passing data between functions (avoiding global variables)
- Input validation and error handling with `try`/`except`
- Loops, conditionals, and string formatting for readable CLI output
- (Upcoming) Sets, dictionaries in depth, and object-oriented programming
